--------------------------------------------------------------------------------
Что сделано (кратко, для пояснения к таблице)
--------------------------------------------------------------------------------

1. HTML — `lang="ru"`, label/id, CSS вместо inline-стилей; в профиле отключены ложные срабатывания на `th:*`.
2. Java — константы `TABLE` в репозиториях; убрано лишнее присваивание в `FavoriteController`; упрощён `AuthController`; исправлена работа с `Integer` в `ReadingPositionService` (`map` вместо лишней проверки `p != null`).
3. Архитектура — `ReaderToc`, `ReaderPaging`, `ComicPdfStorageService`, `ComicController`; укорочен `BookController.read()`.
4. Новые функции (полки, статистика) — осмысленные имена (`queryParams`, `weeklyActivity`), без дублирования «магических» имён.

--------------------------------------------------------------------------------
Формулировка для вставки в отчёт (1 абзац)
--------------------------------------------------------------------------------

По результатам статического анализа IntelliJ IDEA (профиль Project Default) до рефакторинга
зафиксировано **740** предупреждений, после двух проходов исправлений — **222** (**70,3 %**
устранено). Наибольший эффект дала работа с **HTML-шаблонами** (с **549** до единиц
замечаний). В категории **Java** снижено число избыточных объявлений и вероятных ошибок;
длинный метод **`BookController.read()`** разгружен за счёт выноса оглавления, комикса и PDF
в отдельные классы (аналогично разбиению длинного метода в учебном примере с `applyFilters()`).
