ID Описание Шаги воспроизведения Критичность Статус
Д-01 Не сохраняется прогресс чтения: после перезагрузки книга открывается с 1-й страницы 1) Войти как читатель. 2) Открыть текстовую книгу, перелистать на стр. 3–5. 3) Закрыть вкладку или обновить страницу. 4) Снова открыть ту же книгу. Средняя Исправлено
Д-02 Ошибка при загрузке «Статистика» / «Продолжить чтение» или раздела «Комиксы» (сбой разбора дат JSON из Supabase) 1) Войти под пользователем с историей чтения. 2) Открыть «Статистика» или «Комиксы». 3) Дождаться ответа сервера (в логах — ошибка десериализации updated_at). Средняя Исправлено
Д-03 Некорректные данные в форме регистрации: ошибка видна только после отправки, текст не всегда понятен 1) Открыть «Регистрация». 2) Оставить пустые поля или ввести уже занятый логин. 3) Нажать «Зарегистрироваться». Низкая Исправлено
Д-04 Книга не отображается в «Избранное» сразу после добавления (пустой или неполный список) 1) Войти как читатель. 2) На карточке книги нажать «В избранное». 3) Перейти в «Избранное» без перезапуска приложения. Средняя Исправлено
Д-05 Пустой каталог книг при ненастроенном Supabase (нет явного сообщения на экране) 1) Запустить приложение без SUPABASE_URL / SUPABASE_KEY. 2) Открыть «Книги». Средняя Открыто
Д-06 Комикс в каталоге без загруженного PDF: кнопка «Читать» вводит в ошибку вместо понятной подсказки 1) Админ: создать комикс без файла PDF. 2) Читатель: открыть карточку книги. 3) Нажать «Читать». Низкая Исправлено
