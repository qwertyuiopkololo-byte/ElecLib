Задание 8. Ручное тестирование ElecLib

Дополнением к автотестам (задание 7) послужило ручное тестирование по заранее подготовленным сценариям. Проверены веб-интерфейс (Thymeleaf), три новые функции (обложки, комиксы PDF, оглавление) и роли: гость, читатель (app_user), администратор (admin).

Среда: Spring Boot 3.2, браузер Chrome/Edge, Supabase + локальный каталог data/comics/.

Таблица 1. План тестирования

Таблица 1 — План ручных проверок
ID Проверка Шаги Ожидаемый результат Факт / статус
Т-01 Вход читателя 1) Запустить приложение (mvn spring-boot:run). 2) Открыть /login. 3) Ввести логин и пароль существующего пользователя. 4) Нажать «Войти». Переход в каталог /books, в шапке отображаются Книги, Комиксы, Избранное, Полки. Пройдено
Т-02 Вход с неверным паролем 1) На /login ввести существующий логин и неверный пароль. 2) Отправить форму. Сообщение «Неверный логин или пароль», остаёмся на странице входа. Пройдено
Т-03 Регистрация нового пользователя 1) /register — заполнить логин, пароль, имя, фамилию. 2) «Зарегистрироваться». 3) Войти под новой учётной записью. Учётная запись в Supabase, успешный вход, доступ к каталогу. Пройдено
Т-04 Каталог: обложка по URL 1) Войти как админ. 2) Админ → Книги → добавить/изменить книгу. 3) Указать URL обложки (HTTPS). 4) Сохранить. 5) Открыть /books как читатель. На карточке отображается изображение; при пустом URL — заглушка с первой буквой названия. Пройдено
Т-05 Каталог без обложки (заглушка) 1) Создать книгу с пустым полем URL обложки. 2) Открыть каталог. Цветной блок-заглушка с буквой из названия, ссылка на карточку книги работает. Пройдено
Т-06 Добавление комикса (PDF) 1) Админ → Книги → «Добавить». 2) Включить «Комикс», выбрать PDF, заполнить название, автора, жанр, обложку. 3) Сохранить. Запись в Supabase с content_type=comic, файл в data/comics/{id}.pdf. Пройдено
Т-07 Раздел «Комиксы» и читалка PDF 1) Войти читателем с активной подпиской. 2) Открыть /comics. 3) «Читать» у комикса с загруженным PDF. Список только комиксов; PDF.js листает страницы, отображается номер страницы. Пройдено после исправления Д-02
Т-08 Комикс без PDF 1) Создать комикс без загрузки файла или удалить PDF с диска. 2) Открыть карточку книги. Кнопка «Читать» недоступна или подпись «PDF не загружен», без падения приложения. Пройдено
Т-09 Оглавление в текстовой читалке 1) Открыть текстовую книгу с заголовками «Глава 1», «Глава 2» в тексте (отдельные строки). 2) «Оглавление» → выбрать пункт. Панель TOC со списком разделов; переход на нужную страницу. Пройдено
Т-10 Текст без заголовков (пустое TOC) 1) Открыть книгу с сплошным текстом без строк-заголовков. 2) Открыть «Оглавление». Подсказка «Заголовки разделов в тексте не найдены», читалка работает. Пройдено
Т-11 Сохранение прогресса чтения 1) Читать текстовую книгу, перейти на стр. 3–5. 2) Закрыть вкладку. 3) Снова «Продолжить чтение» / открыть ту же книгу. Открывается сохранённая страница (таблица reading_position). Пройдено после исправления Д-01
Т-12 Вход администратора 1) Войти пользователем с ролью admin. 2) Открыть /admin, разделы авторы, жанры, книги, подписки. Доступ к админ-панели; обычный читатель получает 403 на /admin/**. Пройдено
Т-13 Подписка для комикса 1) Войти без активной подписки. 2) Открыть комикс «Читать» / PDF. Перенаправление или сообщение о необходимости подписки; PDF не отдаётся (403). Пройдено
Т-14 Избранное и полки 1) Добавить книгу в избранное. 2) Создать полку, добавить книгу. 3) Проверить /favorites и /shelves. Книга отображается в избранном и на полке; обложки на карточках корректны. Пройдено
