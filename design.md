# ElecLib: Reading Room

Единая система оформления для Thymeleaf-страниц электронной библиотеки.

## Система
- Genre: editorial; scope: app screen.
- Theme: custom Reading Room, спокойный читальный зал с настоящими книжными обложками.
- Светлый бумажный фон, тёмные чернила, зелёный акцент для действий.
- Шапка с текстовым названием и знаком открытой книги; содержимое ограничено 1200px.
- Каталог: заголовок и поиск в одной строке, ниже обложки без внешних карточек.
- Детали книги: обложка слева, описание и действия справа.
- Формы входа: заголовок слева, рабочая форма справа; на телефоне одна колонка.
- Статистика: показатели на общей линии, ниже недельный график.
- Полки: список слева, создание полки справа; на телефоне одна колонка.

## Токены
Источник: `src/main/resources/static/css/tokens.css`.
- `--color-paper`: #f5f3ec; `--color-surface`: #fcfbf6.
- `--color-ink`: #242e29; `--color-muted`: #636b61.
- `--color-accent`: #345b42; `--color-accent-hover`: #254732.
- `--color-rule`: #d9ddd1; `--color-rule-strong`: #7a8771.
- `--font-display`: Georgia, Times New Roman, serif (кириллица, без сетевой загрузки).
- `--font-body`: Segoe UI, system-ui, sans-serif.
- Отдельные токены сохраняют пользовательские шрифты и темы ридера.

## Управление
- Основная кнопка: зелёная, высота от 44px, радиус 6px.
- Вторичная: контурная; опасное действие: явный красный цвет.
- Обязательное кольцо `:focus-visible`, видимые hover/active/disabled.
- Подписи, навигация, формы и таблицы используют основной шрифт.
- Без декоративной анимации; переходы отключаются при reduced motion.

## Экспорт
`style.css` подключает `tokens.css` и `base.css` через относительные CSS imports.
Существующие серверные маршруты, поля форм, JS-обработчики и условия Thymeleaf сохраняются.
Новые функции курсовой должны следовать этой системе оформления.
