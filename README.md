# ElecLib

Веб-приложение электронной библиотеки: каталог с обложками, текстовые книги и **комиксы в PDF**, избранное, полки, статистика и персональные рекомендации.

## Назначение

ElecLib позволяет пользователям:

- просматривать каталог книг в **сетке с обложками**, искать по названию и автору, фильтровать по жанрам;
- читать **текстовые** книги постранично с сохранением позиции;
- читать **комиксы (PDF)** в отдельном разделе и в той же читалке (листание страниц, закладки);
- открывать **оглавление** в текстовой читалке (автопоиск заголовков: «Глава», `§`, римские цифры и др.);
- добавлять закладки и заметки по выделенному тексту (только текстовые книги);
- вести полки «Хочу прочитать», «Читаю», «Прочитано» и свои списки;
- смотреть статистику чтения и баннер «Продолжить чтение»;
- получать **рекомендации** с учётом избранного, истории чтения и полок;
- оставлять отзывы и оценки, оформлять подписку для доступа к чтению.

Администраторы управляют книгами (текст и комиксы), авторами, жанрами, подписками и пользователями.

## Установка

### Требования

- **JDK 17**
- **Maven** (`mvnw` / `mvnw.cmd` в проекте)
- аккаунт **Supabase** (PostgreSQL + REST API)
- для демо-PDF при сборке: **Node.js** (опционально, см. ниже)

### 1. База данных

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните [`supabase_schema.sql`](supabase_schema.sql).
3. В **Settings → API** скопируйте **Project URL** и ключ **service_role**.

Если база уже была создана раньше, добавьте недостающие колонки:

```sql
ALTER TABLE books ADD COLUMN IF NOT EXISTS cover_url text;
ALTER TABLE books ADD COLUMN IF NOT EXISTS content_type text NOT NULL DEFAULT 'text'
  CHECK (content_type IN ('text', 'comic'));
```

### 2. Настройка приложения

`src/main/resources/application-local.properties` (не коммитится):

```properties
supabase.url=https://ВАШ_ПРОЕКТ.supabase.co
supabase.key=ВАШ_SERVICE_ROLE_KEY
```

Или переменные окружения `SUPABASE_URL` и `SUPABASE_KEY`.

Пример: [`application.properties.example`](src/main/resources/application.properties.example).

Параметры в `application.properties`:

| Параметр | По умолчанию | Назначение |
|----------|--------------|------------|
| `eleclib.comics.dir` | `data/comics` | Папка с PDF комиксов на диске сервера |
| `eleclib.sample-comic.enabled` | `true` | Демо-комикс при первом запуске |

### 3. Запуск

```bash
# Windows
.\mvnw.cmd spring-boot:run

# Linux / macOS
./mvnw spring-boot:run
```

Сайт: [http://localhost:8080](http://localhost:8080)  
Доступ с других устройств в локальной сети: `http://IP_ЭТОГО_ПК:8080` (в конфиге `server.address=0.0.0.0`).

### Тесты

```bash
.\mvnw.cmd test
.\mvnw.cmd test "-Dtest=ReaderPagingTest,ReaderTocTest,BookServiceRecommendationTest"
```

## Разделы сайта

| Раздел | URL | Описание |
|--------|-----|----------|
| Каталог | `/books` | Книги и комиксы, поиск, рекомендации |
| Книга | `/books/{id}` | Карточка, отзывы, полки, избранное |

| Комиксы | `/comics` | Только комиксы (нужен вход) |

| Статистика | `/reading/stats` | Прогресс, закладки, заметки |
| Подписка | `/subscription` | Доступ к чтению |
| Жанры | `/genres` | Фильтр по жанру |
| Админка | `/admin` | Контент (роль `admin`) |

## Комиксы (PDF)

### Как устроено

- В Supabase у книги поле `content_type`: `text` или `comic`.
- Сам **файл PDF** хранится на диске сервера: `data/comics/{book_id}.pdf` (папка в `.gitignore`).
- Внешняя ссылка на PDF **не нужна** — загрузка через админку.
- Читалка: [PDF.js](https://mozilla.github.io/pdf.js/), прогресс и закладки по номеру страницы PDF.

### Добавить комикс (админ)

1. **Админ** → **Книги** → **Добавить** (или изменить существующую).
2. Включить **«Комикс (PDF загружается на сервер…)»**.
3. Выбрать файл `.pdf` (до 100 МБ).
4. Заполнить название, автора, жанр; текст можно оставить пустым.
5. **Сохранить** → книга появится в **Комиксы** (`/comics`).

Заменить PDF: **Изменить** книгу → выбрать новый файл → сохранить.

### Демо-комикс

При первом запуске (если `eleclib.sample-comic.enabled=true` и Supabase доступен) создаётся **«Приключение в ElecLib»** (4 страницы).

Пересобрать демо-PDF:

```bash
node scripts/generate-sample-comic.mjs
```

Файл: `src/main/resources/samples/demo-comic.pdf`.

### Видно ли с другого компьютера?

| Что | Где | С другого ПК |
|-----|-----|----------------|
| Название, описание, тип комикса | Supabase | Да, при общем проекте и доступе к сайту |
| Страницы PDF | `data/comics/` на **сервере**, где крутится приложение | Только если открывают **тот же** запущенный сервер |

Каталог комикса в облаке виден везде; **читать** PDF можно только там, где лежит файл. При переносе на другой хост скопируйте папку `data/comics/` или загрузите PDF заново в админке.

## Текстовые книги

### Обложки

- URL в админке: **Книги → URL обложки** (JPG/PNG/WebP по HTTPS).
- Пустой URL — заглушка с первой буквой названия.

### Читалка

- Постраничный текст (~2500 символов), сохранение позиции.
- **Оглавление** — заголовки в тексте отдельными строками (`Глава 1`, `§ 2`, `### Раздел` и т.д.).
- **Закладки**, **заметки** из выделения, **оформление** (светлая / тёмная / сепия).

### Рекомендации

Учитываются избранное, прогресс чтения, полки; недавние жанры и авторы весят сильнее.
