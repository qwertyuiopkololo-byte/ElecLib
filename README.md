# ElecLib

Веб-приложение электронной библиотеки: каталог книг, чтение в браузере, избранное, полки, статистика и персональные рекомендации.

## Назначение

ElecLib позволяет пользователям:

- просматривать каталог книг, искать по названию и автору, фильтровать по жанрам;
- читать книги постранично с сохранением позиции;
- пользоваться **оглавлением** в читалке (автопоиск заголовков: «Глава», `§`, римские цифры и др.) и переходить к разделу одной кнопкой;
- добавлять закладки и заметки по выделенному тексту;
- вести полки «Хочу прочитать», «Читаю», «Прочитано» и свои списки;
- смотреть статистику чтения и баннер «Продолжить чтение»;
- получать **рекомендации** с учётом избранного, истории чтения и полок (с приоритетом недавно начатых книг);
- оставлять отзывы и оценки, оформлять подписку для доступа к чтению.

Администраторы управляют книгами, авторами, жанрами и пользователями через веб-интерфейс.

## Установка

### Требования

- **JDK 17**
- **Maven** (в проекте есть `mvnw` / `mvnw.cmd`)
- аккаунт **Supabase** (PostgreSQL + API)

### 1. База данных

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните скрипт [`supabase_schema.sql`](supabase_schema.sql).
3. В **Settings → API** скопируйте **Project URL** и ключ **service_role**.

### 2. Настройка приложения

Создайте файл `src/main/resources/application-local.properties` (не коммитится в git):

```properties
supabase.url=https://ВАШ_ПРОЕКТ.supabase.co
supabase.key=ВАШ_SERVICE_ROLE_KEY
```

Либо задайте переменные окружения:

```text
SUPABASE_URL=https://ВАШ_ПРОЕКТ.supabase.co
SUPABASE_KEY=ВАШ_SERVICE_ROLE_KEY
```

Пример без секретов: [`application.properties.example`](src/main/resources/application.properties.example).

### 3. Запуск

```bash
# Windows
.\mvnw.cmd spring-boot:run

# Linux / macOS
./mvnw spring-boot:run
```

Сайт откроется по адресу: [http://localhost:8080](http://localhost:8080)

### Тесты

```bash
.\mvnw.cmd test
```

## Использование

| Раздел | URL | Описание |
|--------|-----|----------|
| Каталог | `/books` | Список книг, поиск, рекомендации, «Продолжить чтение» |
| Книга | `/books/{id}` | Описание, отзывы, добавление на полку и в избранное |
| Чтение | `/books/{id}/read` | Читалка: страницы, **оглавление**, закладки, заметки, оформление |
| Избранное | `/favorites` | Сохранённые книги |
| Полки | `/shelves` | Списки «Хочу прочитать», «Читаю», «Прочитано», свои полки |
| Статистика | `/reading/stats` | Прогресс, закладки, заметки, активность по неделям |
| Подписка | `/subscription` | Оформление доступа к чтению |
| Жанры | `/genres` | Книги по жанру |
| Админка | `/admin` | Управление контентом (роль `admin`) |

### Читалка

- Перелистывание страниц, переход по номеру, позиция сохраняется автоматически.
- **Оглавление** — кнопка в панели навигации; для распознавания заголовки должны быть на отдельной строке (`Глава 1`, `§ 2`, `IV. Пролог` и т.д.).
- **Закладки** и **заметки** (заметка создаётся из выделенного текста).
- **Оформление** — тема (светлая / тёмная / сепия), шрифт, размер текста.

### Рекомендации

Блок «Рекомендуем» на каталоге и в избранном подбирает книги того же жанра или автора на основе избранного, прогресса чтения и полок. Недавно открытые книги влияют сильнее остальных.
