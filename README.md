# ElecLib

Веб-приложение электронной библиотеки: каталог с обложками, чтение в браузере, избранное, полки, статистика и персональные рекомендации.

## Назначение

ElecLib позволяет пользователям:

- просматривать каталог книг в **сетке с обложками**, искать по названию и автору, фильтровать по жанрам;
- читать книги постранично с сохранением позиции;
- открывать **оглавление** в читалке (автопоиск заголовков: «Глава», `§`, римские цифры и др.) и переходить к разделу одной кнопкой;
- добавлять закладки и заметки по выделенному тексту;
- вести полки «Хочу прочитать», «Читаю», «Прочитано» и свои списки;
- смотреть статистику чтения и баннер «Продолжить чтение»;
- получать **рекомендации** с учётом избранного, истории чтения и полок (приоритет недавно начатых книг);
- оставлять отзывы и оценки, оформлять подписку для доступа к чтению.

Администраторы управляют книгами (включая URL обложки), авторами, жанрами и пользователями через веб-интерфейс.

## Установка

### Требования

- **JDK 17**
- **Maven** (в проекте есть `mvnw` / `mvnw.cmd`)
- аккаунт **Supabase** (PostgreSQL + REST API)

### 1. База данных

1. Создайте проект на [supabase.com](https://supabase.com).
2. В **SQL Editor** выполните скрипт [`supabase_schema.sql`](supabase_schema.sql).
3. В **Settings → API** скопируйте **Project URL** и ключ **service_role**.

Для обложек в таблице `books` должна быть колонка `cover_url` (есть в актуальном скрипте и в `ALTER` в конце файла).

### 2. Настройка приложения

Создайте файл `src/main/resources/application-local.properties` (не коммитится в git):

```properties
supabase.url=https://ВАШ_ПРОЕКТ.supabase.co
supabase.key=ВАШ_SERVICE_ROLE_KEY
```

Либо задайте переменные окружения `SUPABASE_URL` и `SUPABASE_KEY`.

Пример без секретов: [`application.properties.example`](src/main/resources/application.properties.example).

### 3. Запуск

```bash
# Windows
.\mvnw.cmd spring-boot:run

# Linux / macOS
./mvnw spring-boot:run
```

Сайт: [http://localhost:8080](http://localhost:8080)

### Тесты

```bash
.\mvnw.cmd test
```

Отдельно утилиты читалки и рекомендаций:

```bash
.\mvnw.cmd test "-Dtest=ReaderPagingTest,ReaderTocTest,BookServiceRecommendationTest"
```

## Использование

| Раздел | URL | Описание |
|--------|-----|----------|
| Каталог | `/books` | Сетка книг с обложками, поиск, рекомендации, «Продолжить чтение» |
| Книга | `/books/{id}` | Обложка, описание, отзывы, полки, избранное |
| Чтение | `/books/{id}/read` | Читалка: страницы, оглавление, закладки, заметки, оформление |
| Избранное | `/favorites` | Сохранённые книги |
| Полки | `/shelves` | «Хочу прочитать», «Читаю», «Прочитано», свои полки |
| Статистика | `/reading/stats` | Прогресс, закладки, заметки, активность по неделям |
| Подписка | `/subscription` | Доступ к чтению |
| Жанры | `/genres` | Книги по жанру |
| Админка | `/admin` | Управление контентом (роль `admin`) |

### Обложки книг

- В каталоге, избранном и на полках карточки показывают **изображение обложки** (пропорция 2∶3).
- URL задаётся в админке: **Книги → редактировать → «URL обложки»** (прямая ссылка на JPG/PNG/WebP по HTTPS).
- Если URL пустой — **заглушка** с первой буквой названия.

### Читалка

- Перелистывание страниц, переход по номеру, позиция сохраняется автоматически.
- **Оглавление** — кнопка в панели; заголовки в тексте книги — отдельными строками, например: `Глава 1`, `§ 2`, `IV. Пролог`, `1. Введение`, `### Раздел`.
- **Закладки** и **заметки** (из выделенного текста).
- **Оформление** — светлая / тёмная / сепия, шрифт, размер.

### Рекомендации

Блок «Рекомендуем» учитывает избранное, книги в процессе и прочитанные, полки чтения. Жанры и авторы **недавно открытых** книг влияют сильнее; порядок — по релевантности, не случайный.
